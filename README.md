# Data Analytics — Excel

## Project Overview

This repository contains completed Excel projects from the Data Analytics course.

The projects demonstrate practical skills in data preparation, consolidation, Pivot Tables, business analysis, KPI calculations, ranking, visualization, and A/B testing.

## Projects

### 1. Testing Analyst

File: `01_Testirovanie_Analitik_completed.xlsx`

Tasks completed:

- Combined data from Sheet 1 and Sheet 2
- Created a consolidated dataset
- Built a Pivot Table by week and territory
- Calculated turnover by territory
- Found the top 3 territories by share of total turnover
- Found the top 3 territories by turnover per warehouse for the latest week
- Created weekly turnover dynamics
- Created weekly turnover-per-warehouse dynamics
- Calculated business KPIs
- Created charts and visualizations
